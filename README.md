# Gato's Scene AI (gatos-scene-ai)

이 모듈은 AI를 써서 만들었어요.

## 이게 뭐예요?

지도 이미지를 장면에 올린 다음에는 할 일이 두 가지 남아요. 지도에 그려진 칸과 Foundry 격자를 맞추는 일, 그리고 벽·문·광원을 하나하나 그려 넣는 일이에요. 이 모듈은 그 두 가지를 AI에게 맡겨요.

- **격자 맞추기**: 지도에 그려진 격자를 찾아서 격자 크기, 장면 크기, 배경 위치를 한 번에 맞춰요. 칸 크기는 이미지를 직접 분석해서 소수점 단위까지 재고, AI는 그 결과가 맞는지 확인해요. 격자가 안 그려진 지도는 AI가 문 크기 같은 단서로 축척을 추정해요.
- **벽·문·광원 찾기**: 지도를 여러 조각으로 나눠 AI에게 보여 주고, 벽과 문(비밀 문, 창문 포함), 절벽 같은 고저차, 횃불이나 화로 같은 광원의 위치를 받아와요. 결과는 먼저 캔버스에 미리보기로 보여 주고, 확인한 뒤에 장면에 넣어요.

- **고저차 계산**: 절벽마다 어느 쪽이 높은지, 계단과 경사가 어디 있는지도 AI에게 물어서 바닥 구역마다 높이를 계산해요. 높이는 Foundry의 구역(Region)으로 저장되고, 구역에 들어간 토큰은 고도가 그 높이로 바뀌어요.

AI는 본인 API 키로 연결하거나, 내 컴퓨터에서 돌리는 로컬 LLM에 연결해요. 어떤 게임 시스템에서도 쓰고, GM만 쓸 수 있어요.

이 폴더의 모듈은 Foundry VTT 13 버전용이에요(`master` 브랜치).

## 먼저 준비할 것

1. **gatos-lib** 모듈이 있어야 돌아가요. 둘 다 설치하고 둘 다 켜 주세요.
2. **이미지를 볼 수 있는(비전) AI 모델**이 필요해요. 아래 중 하나면 돼요.
   - Anthropic(Claude), OpenAI, Google Gemini, OpenRouter의 API 키
   - Ollama, LM Studio, llama.cpp 서버처럼 OpenAI 호환 방식으로 말하는 로컬 서버와 비전 모델

벽을 정확히 읽으려면 성능 좋은 모델이 유리해요. 작은 로컬 모델은 격자 확인 정도는 해내지만 벽 좌표는 많이 틀릴 수 있어요.

## 설치하는 법

1. Foundry 첫 화면(설정 화면)에서 **애드온 모듈** 탭을 열고 **모듈 설치**를 눌러요.
2. 창 맨 아래 **매니페스트 URL** 칸에 아래 주소를 붙여 넣고 **설치**를 눌러요.

   ```
   https://raw.githubusercontent.com/snowcat0w0/gatos-scene-ai/master/module.json
   ```

3. "gatos-lib도 함께 설치할까요?" 하고 물어보면 **예**를 눌러요.
4. 월드에 들어가서 **게임 설정 → 모듈 관리**에서 **Gato's Library**와 **Gato's Scene AI**를 둘 다 체크하고 저장해요.

## AI 연결하기

**게임 설정 → 설정 구성 → Gato's Scene AI → AI 연결 설정**을 열어요. Scene AI 창의 **연결 설정** 버튼으로도 열려요.

1. **서비스**를 골라요. 주소와 API 형식이 자동으로 채워져요.
2. **API 키**를 넣어요. 로컬 서버는 비워 둬요.
3. **모델** 칸에 모델 이름을 적어요. **목록**을 누르면 서버가 가진 모델을 불러와서 고를 수 있어요.
4. **연결 테스트**를 눌러요. 작은 테스트 그림을 보내서 모델이 이미지를 실제로 읽는지 확인해 줘요.
5. **저장**을 눌러요.

API 키와 연결 설정은 **지금 쓰는 브라우저에만** 저장돼요. 월드 데이터에 들어가지 않고 플레이어에게도 가지 않아요. 다른 컴퓨터나 다른 브라우저에서는 다시 넣어야 해요.

### 로컬 LLM을 쓸 때

요청을 Foundry를 띄운 브라우저가 직접 보내기 때문에, 로컬 서버가 브라우저 요청(CORS)을 받아 줘야 해요.

- **Ollama**: 환경 변수 `OLLAMA_ORIGINS`에 Foundry 주소(예: `http://localhost:30000`)를 넣고 Ollama를 다시 켜요. 주소는 `http://localhost:11434/v1`이에요.
- **LM Studio**: 서버 설정에서 CORS를 켜요. 주소는 `http://localhost:1234/v1`이에요.
- **llama.cpp 서버**: 따로 할 게 없어요. 주소는 `http://localhost:8080/v1`이에요.

로컬 모델은 느려서 **동시 요청 수**를 1로 두고 **응답 대기 시간**을 넉넉히 주는 게 좋아요.

## 어떻게 써요?

장면을 캔버스에 띄우고, 왼쪽 도구 모음의 **벽** 또는 **조명** 도구에서 마술봉 모양 버튼(**Scene AI**)을 눌러요.

### 1. 격자 맞추기

1. **격자 찾기**를 눌러요. 잠시 뒤 지도 한 칸의 크기, 신뢰도, 적용할 값이 나와요.
2. 값이 그럴듯하면 **장면에 적용**을 눌러요. 격자 크기, 장면 크기, 배경 위치가 바뀌어요. 한 칸이 50픽셀보다 작은 지도(책을 캡처한 작은 그림 같은 것)는 격자 100픽셀에 맞게 장면을 키워요.
3. 마음에 안 들면 **되돌리기**를 눌러요. 적용하기 전 값으로 돌아가요.

**AI로 결과 확인**을 켜 두면 AI가 찾은 격자를 지도 위에 겹쳐 보고 맞는지 판정해요. 칸이 절반이나 두 배 크기로 잡혔으면 알아서 고쳐요. 위치가 살짝 어긋났다고 나오면 적용한 뒤 Gato's Grid Align으로 직접 끌어서 맞추면 돼요.

이미 벽이나 토큰이 있는 장면은 격자를 바꾸면 지도와 어긋날 수 있어서 한 번 더 물어봐요. 격자는 벽을 넣기 전에 먼저 맞추세요.

### 2. 벽·문·광원 찾기

1. 찾을 것(벽, 문·창문, 광원)을 체크해요.
2. **분석 시작**을 눌러요. 버튼 옆에 AI 요청이 몇 번 나가는지 적혀 있어요. 진행 막대가 차는 동안 **중단**할 수 있어요.
3. 끝나면 캔버스에 미리보기가 떠요. 노란 선이 벽, 주황색이 고저차, 보라색이 문, 빨간색이 비밀 문, 하늘색이 창문, 동그라미가 광원이에요. 색이 칠해진 면은 높이 구역이고 그 위의 숫자가 높이예요. 초록 선은 계단·경사예요.
4. 괜찮으면 **장면에 적용**, 아니면 **버리기**를 눌러요.

적용한 뒤에는 평소처럼 벽 도구로 틀린 곳을 고치면 돼요. AI가 만든 벽, 광원, 높이 구역에는 표시가 남아 있어서, 창 아래의 **AI가 만든 벽·광원·높이 구역 지우기**로 그것만 골라 지울 수 있어요. 직접 만든 것은 건드리지 않아요.

옵션은 이래요.

- **벽 찾는 방식**: 기본값인 **AI 좌표**는 AI가 벽 좌표를 직접 읽어요. 대부분의 지도에서 무난해요. **픽셀 윤곽 추적(실험적)**은 AI가 어디가 바닥인지만 알려 주고, 벽 선은 이미지에서 바닥과 벽이 갈리는 경계를 직접 따라 그려요. 바닥과 벽이 뚜렷이 나뉜 동굴이나 던전에서 선이 더 정밀하지만, AI가 바닥 범위를 한 칸만 틀려도 선이 계단처럼 깨져요. 두 방식을 다 돌려 보고 나은 쪽을 쓰세요.
- **고저차(절벽) 처리**: 절벽 끝이나 단차를 어떤 벽으로 만들지 정해요. 기본값인 투명 벽은 이동만 막고 시야는 통과시켜요. 지형 벽, 일반 벽, 높이 벽, 만들지 않음 중에서도 고를 수 있어요. **높이 벽**은 위쪽 바닥의 높이를 벽 꼭대기로 넣은 일반 벽이에요. Wall Height 모듈이 켜져 있으면 절벽 위에서는 아래가 보이고, 아래에서는 위가 가려져요. Wall Height가 꺼져 있거나 높이를 모르는 절벽은 투명 벽으로 만들어요.
- **높이 구역 만들기**: 켜 두면 고저차를 계산해요. 자세한 내용은 아래 "고저차 계산"을 보세요.
- **높이 차 기본값(칸)**: 지도에 높이가 적혀 있지 않은 절벽·계단·경사의 높이 차예요. 5ft 격자에서 2칸이면 10ft예요.
- **타일 크기**: AI에게 한 번에 보여 주는 범위예요. 작게 하면 정확해지지만 요청 횟수가 늘어요.
- **좌표 맞춤**: AI가 좌표로 준 것(문, 얇은 벽, AI 좌표 방식의 벽)을 격자의 어느 단위에 맞출지 정해요. 윤곽 추적으로 그린 벽 선에는 적용되지 않아요.
- **벽 선을 그림에 맞추기**: AI는 벽이 어디로 지나가는지는 잘 읽지만 위치는 반 칸쯤 어긋나요. 이 옵션을 켜 두면 AI가 준 벽을 반 칸 이내에서 그림에 그려진 실제 선으로 옮겨요. 이어진 곳과 열린 곳은 그대로 두고 위치만 고치고, 선이 뚜렷하지 않은 구간은 건드리지 않아요. AI 요청은 늘지 않아요. 벽이 엉뚱한 선(격자선이나 가구 테두리)에 붙으면 끄고 다시 분석하세요.
- **광원 반경 배율**: 기본은 횃불이 밝은 빛 4칸, 어두운 빛 8칸이에요.
- **먼저 지도 전체를 훑어보기**: 지도 종류와 벽이 어떻게 그려졌는지 먼저 파악하게 해요. 요청이 한 번 더 나가요.

### 3. 고저차 계산

**높이 구역 만들기**를 켜고 분석하면 이렇게 돼요.

1. AI가 절벽 선마다 어느 쪽이 높은지, 계단·경사·"up/down" 통로에는 통로를 가로지르는 선과 높은 쪽을 알려 줘요.
2. 모듈이 벽과 그 선들로 바닥을 구역으로 나누고, 가장 넓은 구역을 0으로 두고 나머지 구역의 높이를 계산해요. 지도에 높이가 안 적혀 있으면 **높이 차 기본값**을 써요.
3. **장면에 적용**을 누르면 구역마다 Foundry 구역(Region)이 하나씩 생겨요. 이름은 "높이 +10 ft" 같은 식이에요.
4. 그 구역 안에서 이동을 마친 토큰은 고도가 구역의 높이로 바뀌어요. 날고 있는 토큰(고도가 바닥 높이와 다른 토큰)과, 이동하면서 고도를 직접 바꾼 토큰은 건드리지 않아요.

높이를 고치려면 구역 도구에서 그 구역을 열고 **고도 하단** 값을 바꾸면 돼요. 구역의 모양도 평소처럼 고칠 수 있어요.

토큰 고도를 자동으로 바꾸는 기능은 **게임 설정 → 설정 구성 → Gato's Scene AI → 토큰 고도를 높이 구역에 맞추기**에서 끌 수 있어요.

고저차가 계산되지 않는 경우도 있어요. 절벽 선이 벽에서 벽까지 이어지지 않아서 그 끝을 돌아갈 수 있으면, 양쪽이 같은 구역이라 높이 차를 줄 수 없어요. AI가 높은 쪽을 알려 주지 않은 선도 마찬가지예요. 분석 로그에 "정하지 못한 것 N개"로 나와요. 이럴 때는 구역을 직접 그리고 고도 하단을 넣어도 되지만, 직접 그린 구역은 토큰 고도를 바꾸지 않아요.

## 알아 둘 것

- **AI 결과는 초안이에요.** 벽이 빠지거나 살짝 어긋날 수 있으니 미리보기를 보고, 적용한 뒤 손봐 주세요. 윤곽 추적은 바닥과 벽의 색이나 경계선이 뚜렷한 지도에서만 쓸 만하고, 숲처럼 경계가 흐린 야외 지도에는 맞지 않아요.
- **높이 숫자는 대부분 추정이에요.** 지도에 높이가 적혀 있는 경우는 드물어서, 대개 기본값(2칸)이 들어가요. 미리보기의 숫자를 보고 적용한 뒤 구역에서 고쳐 주세요.
- **경사는 계단식으로만 표현해요.** 경사로나 계단은 가운데 선 하나를 기준으로 양쪽 높이가 달라져요. 서서히 올라가는 높이는 다루지 않아요.
- **토큰 고도는 이동이 끝난 자리 기준으로 바뀌어요.** 이동 경로 중간의 오르내림은 거리에 반영되지 않아요.
- **지도 이미지가 AI 서비스로 전송돼요.** 외부 API를 쓰면 요청마다 요금이 나가요. 큰 지도는 타일이 많아지니 요청 횟수를 먼저 확인하세요.
- 육각 격자 장면은 벽·광원 분석을 지원하지 않아요.
- 배경이 다른 사이트에 올라가 있고 그 사이트가 읽기를 막으면 분석할 수 없어요. 이미지를 Foundry 데이터 폴더로 옮기면 돼요.
- OpenAI는 API 키가 틀려도 "서버에 연결하지 못했습니다"로 나와요. 그 메시지가 뜨면 키부터 확인하세요.
- 매크로나 다른 모듈에서는 `game.modules.get("gatos-scene-ai").api`로 같은 기능(`detectGrid`, `analyze`, `applyResult`, `removeGenerated`, `groundAt`)을 부를 수 있어요.
