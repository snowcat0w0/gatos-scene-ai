# Gato's Scene AI (gatos-scene-ai)

이 모듈은 AI를 써서 만들었어요.

## 이게 뭐예요?

지도 이미지를 장면에 올린 다음에는 할 일이 두 가지 남아요. 지도에 그려진 칸과 Foundry 격자를 맞추는 일, 그리고 벽·문·광원을 하나하나 그려 넣는 일이에요. 이 모듈은 그 두 가지를 AI에게 맡겨요.

- **격자 맞추기**: 지도에 그려진 격자를 찾아서 격자 크기, 장면 크기, 배경 위치를 한 번에 맞춰요. 칸 크기는 이미지를 직접 분석해서 소수점 단위까지 재고, AI는 그 결과가 맞는지 확인해요. 격자가 안 그려진 지도는 AI가 문 크기 같은 단서로 축척을 추정해요.
- **벽·문·광원 찾기**: 지도를 여러 조각으로 나눠 AI에게 보여 주고, 벽과 문(비밀 문, 창문 포함), 횃불이나 화로 같은 광원의 위치를 받아와요. 결과는 먼저 캔버스에 미리보기로 보여 주고, 확인한 뒤에 장면에 넣어요.

AI는 본인 API 키로 연결하거나, 내 컴퓨터에서 돌리는 로컬 LLM에 연결해요. 어떤 게임 시스템에서도 쓰고, GM만 쓸 수 있어요.

이 폴더의 모듈은 Foundry VTT 13 버전용이에요(`master` 브랜치).

## 먼저 준비할 것

1. **gatos-lib** 모듈이 있어야 돌아가요. 둘 다 설치하고 둘 다 켜 주세요.
2. **이미지를 볼 수 있는(비전) AI 모델**이 필요해요. 아래 중 하나면 돼요.
   - Anthropic(Claude), OpenAI, Google Gemini, OpenRouter의 API 키
   - Ollama, LM Studio, llama.cpp 서버처럼 OpenAI 호환 방식으로 말하는 로컬 서버와 비전 모델

벽을 정확히 읽으려면 성능 좋은 모델이 유리해요. 작은 로컬 모델은 격자 확인 정도는 해내지만 벽 좌표는 많이 틀릴 수 있어요.

## 설치하는 법

1. Foundry 첫 화면(설정 화면)에서 **애드온 모듈** 탭을 열고 **모듈 설치**를 눌러요.
2. 창 맨 아래 **매니페스트 URL** 칸에 아래 주소를 붙여 넣고 **설치**를 눌러요.

   ```
   https://raw.githubusercontent.com/snowcat0w0/gatos-scene-ai/master/module.json
   ```

3. "gatos-lib도 함께 설치할까요?" 하고 물어보면 **예**를 눌러요.
4. 월드에 들어가서 **게임 설정 → 모듈 관리**에서 **Gato's Library**와 **Gato's Scene AI**를 둘 다 체크하고 저장해요.

## AI 연결하기

**게임 설정 → 설정 구성 → Gato's Scene AI → AI 연결 설정**을 열어요. Scene AI 창의 **연결 설정** 버튼으로도 열려요.

1. **서비스**를 골라요. 주소와 API 형식이 자동으로 채워져요.
2. **API 키**를 넣어요. 로컬 서버는 비워 둬요.
3. **모델** 칸에 모델 이름을 적어요. **목록**을 누르면 서버가 가진 모델을 불러와서 고를 수 있어요.
4. **연결 테스트**를 눌러요. 작은 테스트 그림을 보내서 모델이 이미지를 실제로 읽는지 확인해 줘요.
5. **저장**을 눌러요.

API 키와 연결 설정은 **지금 쓰는 브라우저에만** 저장돼요. 월드 데이터에 들어가지 않고 플레이어에게도 가지 않아요. 다른 컴퓨터나 다른 브라우저에서는 다시 넣어야 해요.

### 로컬 LLM을 쓸 때

요청을 Foundry를 띄운 브라우저가 직접 보내기 때문에, 로컬 서버가 브라우저 요청(CORS)을 받아 줘야 해요.

- **Ollama**: 환경 변수 `OLLAMA_ORIGINS`에 Foundry 주소(예: `http://localhost:30000`)를 넣고 Ollama를 다시 켜요. 주소는 `http://localhost:11434/v1`이에요.
- **LM Studio**: 서버 설정에서 CORS를 켜요. 주소는 `http://localhost:1234/v1`이에요.
- **llama.cpp 서버**: 따로 할 게 없어요. 주소는 `http://localhost:8080/v1`이에요.

로컬 모델은 느려서 **동시 요청 수**를 1로 두고 **응답 대기 시간**을 넉넉히 주는 게 좋아요.

## 어떻게 써요?

장면을 캔버스에 띄우고, 왼쪽 도구 모음의 **벽** 또는 **조명** 도구에서 마술봉 모양 버튼(**Scene AI**)을 눌러요.

### 1. 격자 맞추기

1. **격자 찾기**를 눌러요. 잠시 뒤 지도 한 칸의 크기, 신뢰도, 적용할 값이 나와요.
2. 값이 그럴듯하면 **장면에 적용**을 눌러요. 격자 크기, 장면 크기, 배경 위치가 바뀌어요.
3. 마음에 안 들면 **되돌리기**를 눌러요. 적용하기 전 값으로 돌아가요.

**AI로 결과 확인**을 켜 두면 AI가 찾은 격자를 지도 위에 겹쳐 보고 맞는지 판정해요. 칸이 절반이나 두 배 크기로 잡혔으면 알아서 고쳐요. 위치가 살짝 어긋났다고 나오면 적용한 뒤 Gato's Grid Align으로 직접 끌어서 맞추면 돼요.

이미 벽이나 토큰이 있는 장면은 격자를 바꾸면 지도와 어긋날 수 있어서 한 번 더 물어봐요. 격자는 벽을 넣기 전에 먼저 맞추세요.

### 2. 벽·문·광원 찾기

1. 찾을 것(벽, 문·창문, 광원)을 체크해요.
2. **분석 시작**을 눌러요. 버튼 옆에 AI 요청이 몇 번 나가는지 적혀 있어요. 진행 막대가 차는 동안 **중단**할 수 있어요.
3. 끝나면 캔버스에 미리보기가 떠요. 노란 선이 벽, 보라색이 문, 빨간색이 비밀 문, 하늘색이 창문, 동그라미가 광원이에요.
4. 괜찮으면 **장면에 적용**, 아니면 **버리기**를 눌러요.

적용한 뒤에는 평소처럼 벽 도구로 틀린 곳을 고치면 돼요. AI가 만든 벽과 광원에는 표시가 남아 있어서, 창 아래의 **AI가 만든 벽·광원 지우기**로 그것만 골라 지울 수 있어요. 직접 그린 벽은 건드리지 않아요.

옵션은 이래요.

- **타일 크기**: AI에게 한 번에 보여 주는 범위예요. 작게 하면 정확해지지만 요청 횟수가 늘어요.
- **좌표 맞춤**: AI가 준 좌표를 격자의 어느 단위에 맞출지 정해요. 직각 위주의 던전은 반 칸이 깔끔하고, 동굴처럼 구불구불한 지도는 1/4칸이나 맞춤 없음이 나아요.
- **광원 반경 배율**: 기본은 횃불이 밝은 빛 4칸, 어두운 빛 8칸이에요.
- **먼저 지도 전체를 훑어보기**: 지도 종류와 벽이 어떻게 그려졌는지 먼저 파악하게 해요. 요청이 한 번 더 나가요.

## 알아 둘 것

- **AI 결과는 초안이에요.** 벽이 빠지거나 살짝 어긋날 수 있으니 미리보기를 보고, 적용한 뒤 손봐 주세요. 벽이 굵게 또렷이 그려진 던전·건물 지도에서 잘 맞고, 숲이나 동굴처럼 경계가 흐린 지도는 덜 맞아요.
- **지도 이미지가 AI 서비스로 전송돼요.** 외부 API를 쓰면 요청마다 요금이 나가요. 큰 지도는 타일이 많아지니 요청 횟수를 먼저 확인하세요.
- 육각 격자 장면은 벽·광원 분석을 지원하지 않아요.
- 배경이 다른 사이트에 올라가 있고 그 사이트가 읽기를 막으면 분석할 수 없어요. 이미지를 Foundry 데이터 폴더로 옮기면 돼요.
- OpenAI는 API 키가 틀려도 "서버에 연결하지 못했습니다"로 나와요. 그 메시지가 뜨면 키부터 확인하세요.
- 매크로나 다른 모듈에서는 `game.modules.get("gatos-scene-ai").api`로 같은 기능(`detectGrid`, `analyze`, `applyResult`, `removeGenerated`)을 부를 수 있어요.
